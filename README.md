# 墨读 MoRead

> 专注纯净阅读与学术排版的 macOS 轻量 Markdown 编辑/阅读器。

墨读（MoRead）专为追求极致沉浸阅读与写作体验的学者、写作者与工程师打造。采用 Swift + AppKit 原生架构，参考 Typora 的黑白灰克制排版风格，全面支持 CommonMark 与 GFM 标准，离线集成学术级 MathJax 3 矢量数学公式渲染与代码语法高亮。

---

## 🌟 核心特性

- **极致轻量原生**：基于 macOS Swift + AppKit 原生架构，安装包仅约 1.7 MB，冷启动极快，内存占用低。
- **单窗口所见即所得编辑**：支持原地直读直编与 Markdown 源码模式一键切换（`Cmd+Shift+S`），原生安全原子保存（`Cmd+S`）。
- **学术级数学排版**：100% 离线 MathJax 3 矢量渲染，支持复杂矩阵、方程组对齐、分段函数等 LaTeX 环境。
- **阅读沉浸排版**：支持文档多级大纲（TOC）、文内全文搜索（`Cmd+F`）、多档排版宽度与字号缩放。
- **安全与防丢防护**：无联网遥测；未保存退出自动拦截提醒，保障数据安全。

## 🚀 安装指南

1. 进入 [Releases 页面](https://github.com/zuoruchun/moread/releases) 下载最新的 `MoRead-xxx-arm64.dmg`。
2. 双击打开 DMG 文件，将 **MoRead** 图标拖拽至 **Applications**（应用程序）文件夹中。
3. **首次打开权限处理**：
   由于个人开源应用未包含苹果商业付费证书签名，若首次打开出现“无法验证开发者”的安全提示，只需打开终端运行以下命令即可正常使用：
   ```bash
   xattr -cr /Applications/MoRead.app
   ```
   *(或在 Mac「系统设置」->「隐私与安全性」中点击「仍要打开」)*
