# MoRead 缺陷修复与验证

最后更新：2026-10-07

## 当前结论

当前本地工程为 V1.5.1 本地修复版。本次确认并修复 PDF 长单页、导出干扰编辑状态、图片路径与隐私设置，以及渲染编辑切换标签丢失内容的问题。以下保留 V1.5 功能概况；验证范围以测试报告为准：
- **阅读／编辑独立状态**：默认打开文件进入阅读状态，禁用正文、源码、代码块及复选框输入，原生菜单与快捷键受保护；右上角新增“编辑／结束编辑”按钮与退出确认对话框（保存/放弃/取消）；设置增加“打开文件时：阅读模式/编辑模式”。
- **多标签页与多窗口快捷键规范**：`Cmd+T` 新建标签页，`Cmd+W` 关闭标签页，`Cmd+N` 新建窗口。本次补上渲染编辑离开标签时的内容缓存，真实 WebKit 验证正文、代码、语言、公式及源码修改不丢失、不污染其他文档；不宣称跨标签撤销历史已验证。
- **A4 分页 PDF 导出**：文件菜单“导出为 PDF…”(`Cmd+Option+P`) 使用独立文档快照和系统打印分页，而非整页长截图。保留代码颜色与公式，支持长代码和表格跨页，不修改编辑区、不标记 Markdown 已保存；遵守远程图片设置，图片失败显示占位说明。
- **设置面板分类整理**：设置对话框重构为三组清晰类别（阅读与视图、保存与安全、网络与隐私），移除冗余提示文案，排版更整洁紧凑。
- **保存安全与原文保护**：无修改时不写盘，未修改内容不重新排版；保留 BOM (`0xEF, 0xBB, 0xBF`) 与 CRLF 换行；Turndown 清理 `mored://` 协议与 `<mark class="search-highlight">` 标签。
- **外部修改冲突与本地恢复草稿**：多文件 `FileWatcher` 监听；外部修改冲突横幅提示；保存前磁盘指纹校验；防抖自动恢复草稿与异常恢复提示弹窗。
- **阅读位置记忆**：每个文档记录阅读滚动比例；重新打开或源码/渲染切换时恢复位置；显式锚点优先。
- **另存为与保存副本**：系统文件菜单增加“另存为…”(`Cmd+Option+Shift+S`) 与“保存副本…”。
- **图片放大与搜索**：点击图片灯箱放大居中显示（Esc 退出）；远程图片隐私设置；全模式支持 `Cmd+F` 页面内搜索。
- **单文件打开卡顿修复**：去除单文件加载时强制深度递归扫描父目录逻辑；Swift 原生 `scanDirectory` 限制 `maxDepth: 2`（单次上限 500 项），彻底消除几千层目录卡顿。

发布版本为 V1.5.1：[GitHub Release](https://github.com/zuoruchun/moread/releases/tag/v1.5.1)。本地 `/Applications/MoRead.app` 未替换，所有历史安装包保留在 `dist/` 中。

## 验证结果及边界

- `npm test`：9 个测试套件，70 项通过，新增 5 项 PDF 快照、隐私与状态保护测试。
- `npm run test:native`：8 个测试组，30 项原生 Swift 测试 100% 通过（覆盖 BOM、CRLF、超大文件基准、安全边界、多文件监听与不可变 fixture 校验）。
- `npm run test:renderer:bridge`：57 项实际 WebKit 容器集成测试 100% 通过（涵盖真实 WKWebView 交互、代码编辑/高亮/撤销、自动保存、外部冲突保护、文件树更新与设置持久化）。
- `npm run test:pdf`：50 项真实 WebKit/PDF 检查通过；长文档与未保存渲染文档各 9 页 A4，短文档、空文档、缺失图片各 1 页。另用 PDF 文本提取核对全部代码行、表格行和段落，并渲染页面检查边界。
- `./build-native.sh`：生成 `dist/MoRead-1.5.1-arm64.dmg` 与 ZIP；签名、DMG 完整性及校验和验证通过。未安装到 `/Applications`。
- 本次未重新测试 Finder 冷启动、窗口拖动、原生保存面板取消操作及全部 V1.5 新增交互，不将现有套件通过解释为软件无其他缺陷。
