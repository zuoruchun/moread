# MoRead V1.4.0 发布说明

## 改进与修复

- 在渲染模式中直接修改代码块内容和语言，实时语法高亮，复制和保存使用当前内容。
- 补充 Bash 自定义命令、参数和数字着色；未知语言安全显示为纯文本。
- 保留代码缩进、尾部空行和内嵌反引号，修复鼠标无法命中代码编辑区域的问题。
- 左上角改为单一侧边栏按钮，大纲与文件列表切换放在侧边栏内部。
- 修复当前文件名称显示与大纲中的 Markdown 转义字符；仅保留右上角源码/渲染切换。
- 主题、字号和阅读宽度集中到原生菜单“墨读 MoRead → 设置…”（Cmd+,）。

## 验证

- 49 项单元测试、27 项原生测试、36 项实际 WebKit 与文件桥接检查通过。
- 已安装应用实测代码编辑、中文内容保存、语言修改和高亮显示。
- DMG 完整性、应用签名及 DMG/ZIP 的 SHA-256 校验通过。
- 本版本未重新完整验证真实 Finder 冷启动、窗口拖动和全部应用生命周期场景。

## 已知问题

单独打开 Markdown 文件后，自动扫描所在目录在部分实机场景中可能超时。若文件列表提示超时，请通过“文件 → 打开文件夹”明确选择所在目录。此问题尚未修复，也不计入本版本通过项。

## 下载与系统要求

适用于 Apple Silicon（arm64），需要 macOS 14 或更新版本。提供 DMG、ZIP 及 SHA256SUMS.txt。应用采用本地临时签名，未经过 Apple 公证。
